# Concept registry

Where each concept is first introduced and where it is revisited. Read this
before drafting so a chapter references a concept rather than re-teaching it —
repetition is the most common defect `/review` catches. `/approve` updates this
file; do not edit chapter status by hand.

Prefill from the frozen TOC (Stage 3), one row per concept, assigned to the
chapter that owns it.

| Concept | First introduced | Revisited in | Approved one-line definition |
|---------|------------------|--------------|------------------------------|
| [concept] | ch[N] | ch[N], ch[N] | [definition, matching terminology.md] |
