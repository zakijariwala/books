# AGENTS.md

This project's instructions for AI coding assistants live in **`CLAUDE.md`**.
`AGENTS.md` exists so tools that look for this filename find the same guidance.

Read `CLAUDE.md` for: the non-negotiable rules, the staged writing workflow and
agent skills, the build and check commands, and the git workflow. Then read
`HANDOVER.md` for current state, `BOOK-SPEC.md` for positioning and structure,
`docs/buyer.md` for the reader, `voice/sample.md` for the voice (the only style
source), `STYLE-GUIDE.md` for prose mechanics, and `GOVERNANCE.md` for workflow,
fact-verification, and copyright discipline.
