## The scenario

Original enterprise with a monolithic application nobody wants to touch,
running on hardware under a lease that expires. 250 words.

Stack to include: an application server tier, a large relational database,
batch jobs bound to a scheduler, Active Directory authentication, a file share
several systems depend on.

Constraints to state:

- Lease expiry sets an immovable date
- The team has no Kubernetes experience
- One overnight batch window cannot move
- Regulated data in one of the schemas

The date constraint and the capability constraint together drive the answer,
and neither is technical. That is the point of this chapter.
