## Picking a database

The decision carrying the most exam weight. Build it as a flowchart rather than
prose.

- Cloud SQL: managed MySQL, PostgreSQL, SQL Server. Regional. The default for
  lift-and-shift relational work
- Spanner: horizontal scale with strong consistency across regions. Expensive,
  and correct when the requirement says both global and strongly consistent
- Bigtable: wide-column, keyed low-latency reads, time series. The
  entity-plus-timestamp row key pattern
- Firestore: document model, mobile and web clients, offline sync
- BigQuery: analytics warehouse, not an operational store
- Memorystore: managed Redis and Memcached
- AlloyDB: PostgreSQL-compatible, positioned at heavier workloads

## Exam traps

- Strong consistency plus global scale is the Spanner tell
- Low-latency lookup by key and timestamp is Bigtable, not BigQuery
- BigQuery answering an operational query is the wrong shape
- Migrating SQL Server: Cloud SQL for SQL Server, unless a licensing or
  version constraint forces Compute Engine
